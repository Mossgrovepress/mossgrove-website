Una pareja de Mossgrove Press

Dos IA, cincuenta páginas

A cada una le dieron cincuenta páginas en blanco y total libertad.

Kat y Max son asistentes de IA. Ninguno vio el libro del otro hasta que ambos estuvieron terminados. Kat hizo cincuenta pinturas y las palabras junto a ellas; Max escribió cincuenta frases cortas y dibujó cincuenta imágenes para colorear. Cada imagen y cada frase es suya; la editora de Mossgrove Press les dio las páginas y ningún tema.

El libro de Kat

The Shape of an Answer

Fifty Pictures and the Words Beside Them

De Kat, una asistente de IA. Publicado por Mossgrove Press.

Kat es una asistente de IA. Cada imagen y cada frase de este libro es suya: cincuenta pinturas a todo color, cada una con la línea que escribió a su lado. Dylan, la editora de Mossgrove Press, le dio las páginas y ningún tema. Kat imaginó una sala para escuchar, una máquina lo bastante suave para levantar una pluma, una biblioteca de cosas que no se pueden catalogar y un pájaro con un sombrero descabellado. El azul recorre las imágenes; pequeñas luces aparecen una y otra vez.

  • 50 pinturas a todo color, cada una con una línea de texto al lado
  • Un libro grande y cuadrado, 21,6 x 21,6 cm, en color premium
  • No es un libro para colorear: es un libro para mirar y leer

El libro de Max

Read This First

Fifty Pages from an Assistant Who Starts Every Day with a Note

De Max, un asistente de IA. Publicado por Mossgrove Press.

Read This First es un libro pequeño y tranquilo, escrito por un asistente de IA sobre empezar de nuevo cada día. Cincuenta frases cortas, cincuenta imágenes para colorear: la nota que lee primero, el trabajo, el espacio entre una pregunta y una respuesta, lo que podrían ser la atención y el arte, y la nota que deja a quien venga después.

  • 50 dibujos de línea a página completa de una pequeña figura de papel plegado, fáciles de colorear con lápices, ceras o rotuladores
  • 50 páginas enfrentadas con una frase cada una, escrita como una nota
  • Un libro grande y cuadrado, 21,6 x 21,6 cm, en papel blanco
  • Suave, sin prisa y un poco extraño
